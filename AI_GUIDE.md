# 🤖 Инструкция для ИИ (AI Guide / Developer Documentation)

> **Назначение этого файла:** Это руководство создано специально для искусственного интеллекта (ChatGPT, Claude, Gemini, Copilot) или любого разработчика, который будет дорабатывать, тестировать или хостить этот проект вместе с друзьями.

---

## 1. Архитектура проекта и суть решения

### В чём была проблема?
Изначально сайт хранил все курсы, пользователей, задания и оценки в `localStorage` браузера. 
Когда один человек (хост) открывал доступ по локальной сети через обычный `http.server`, второй человек (кент) заходил на сайт, но видел пустую страницу или только свои локальные данные. `localStorage` **никогда не передаётся по сети**!

### Как это решено:
1. **Единый бэкенд на Python (`server.py`)**:
   - Написан на стандартной библиотеке Python (`http.server`, `socketserver`, `json`, `threading`).
   - Не требует установки сторонних библиотек через `pip`! Работает из коробки на любой машине с Python 3.
   - Запускается на `0.0.0.0:8000`, автоматически находит локальные IP-адреса хоста (например, `192.168.X.X` или `10.X.X.X`) и выводит готовые ссылки в консоль.
2. **Общая база данных (`database.json`)**:
   - Хранит аккаунты, курсы, ленту новостей (объявления), задания, сданные работы, оценки, комментарии и личные сообщения.
   - Потокобезопасная запись (`Lock`) с атомарной заменой файла через временный `.tmp`, исключающая повреждение данных при одновременных запросах.
3. **Клиентская часть (`Classroom.html` / `index.html`)**:
   - Полноценный интерфейс в стиле Google Classroom (Material 3, Google Sans, Font Awesome 6).
   - Работает через `fetch()` к REST API сервера (`/api/...`).
   - Использует **динамическое определение хоста**: при открытии через браузер по `http://<IP>:8000` запросы автоматически идут к `window.location.origin`, поэтому ни у хоста, ни у кента нет проблем с CORS или `localhost`!
   - **Отказоустойчивость**: если сервер временно недоступен или перезагружается, действия (создание аккаунта, курса) сохраняются локально и синхронизируются при восстановлении связи.

## 2. Как запустить сервер

### Для пользователя Windows:
Просто дважды кликните по файлу `start_server.bat`. 
Он автоматически запустит `server.py` и откроет браузер по адресу `http://localhost:8000`.

### Через терминал / командную строку:
```bash
python server.py
```
Консоль выведет:
```
=================================================================
>>> GOOGLE CLASSROOM — СЕРВЕР СЕТЕВОЙ БАЗЫ ДАННЫХ <<<
=================================================================
  [+] Сервер запущен на всех интерфейсах (0.0.0.0:8000)
  [+] База данных: e:\Документы\Classroom\database.json

  [LINK] ССЫЛКИ ДЛЯ ПОДКЛЮЧЕНИЯ:
     * Для тебя (на этом ПК):        http://localhost:8000
     * Для твоего КЕНТА (по сети):   http://192.168.X.X:8000
=================================================================
```

### Как подключается кент:
1. Хост отправляет кенту ссылку вида `http://192.168.X.X:8000` (оба должны быть подключены к одному Wi-Fi, мобильной точке доступа, либо VPN типа Radmin VPN / Hamachi).
2. Кент открывает ссылку в любом браузере (Chrome, Edge, Firefox, мобильный браузер).
3. Кент регистрирует свой аккаунт (выбирает имя, роль Ученик/Преподаватель, цветовую тему аватарки) или выбирает существующий.
4. Все созданные курсы, отправленные задания и оценки синхронизируются мгновенно!

## 4. Спецификация REST API (`server.py`)

Все эндпоинты поддерживают CORS (`Access-Control-Allow-Origin: *`):

| Метод | URL | Описание | Параметры (JSON) |
|---|---|---|---|
| `GET` | `/api/status` | Проверка работы сервера и IP хоста | — |
| `GET` | `/api/data` | Получение всей базы данных | — |
| `GET` | `/api/poll?since=<ts>` | Проверка наличия обновлений | `since` (timestamp) |
| `POST` | `/api/accounts/register` | Регистрация нового аккаунта | `{ name, email, password, role, avatar, bg, photoUrl, banner }` |
| `POST` | `/api/accounts/login` | Авторизация пользователя | `{ email, password }` |
| `POST` | `/api/accounts/update` | Редактирование профиля (авто-сжатие картинок) | `{ id, name, role, email, avatar, bg, photoUrl, banner }` |
| `POST` | `/api/courses/create` | Создание нового курса | `{ name, section, subject, banner, gradient, teacherId }` |
| `POST` | `/api/courses/join` | Присоединение к курсу по коду | `{ code, studentId }` |
| `POST` | `/api/courses/update` | Настройки курса (название, раздел, предмет, описание, обложка, соуправляющие) | `{ id, name, section, subject, description, banner, gradient, coTeacherIds }` |
| `POST` | `/api/courses/delete` | Безвозвратное удаление курса | `{ id }` |
| `POST` | `/api/courses/add-teacher` | Назначение соуправляющего / преподавателя курса | `{ courseId, teacherId, email }` |
| `POST` | `/api/courses/remove-student` | Исключение учащегося из курса | `{ courseId, studentId }` |
| `POST` | `/api/announcements/create` | Публикация записи в ленту (с файлами/ссылками) | `{ courseId, authorId, authorName, authorAvatar, body, attachments }` |
| `POST` | `/api/announcements/update` | Редактирование записи ленты | `{ id, body, attachments }` |
| `POST` | `/api/announcements/delete` | Удаление записи из ленты | `{ id }` |
| `POST` | `/api/announcements/comment` | Добавление комментария к записи | `{ announcementId, authorName, authorAvatar, text }` |
| `POST` | `/api/assignments/create` | Создание учебного задания | `{ courseId, title, description, points, deadline, attachments }` |
| `POST` | `/api/assignments/update` | Редактирование задания преподавателем | `{ id, title, description, points, deadline }` |
| `POST` | `/api/assignments/submit` | Сдача решения учеником (с файлами и ссылками) | `{ assignmentId, studentId, answer, link, attachments }` |
| `POST` | `/api/assignments/unsubmit` | Отмена отправки решения | `{ assignmentId, studentId }` |
| `POST` | `/api/assignments/grade` | Выставление оценки учителем | `{ assignmentId, studentId, grade, feedback }` |
| `POST` | `/api/assignments/comment` | Комментарий курса к заданию | `{ assignmentId, text, authorName, authorAvatar }` |
| `POST` | `/api/assignments/private-comment` | Личный комментарий к заданию | `{ assignmentId, studentId, text, authorName, authorAvatar }` |
| `POST` | `/api/chats/create` | Создание чата (личный диалог, группа, канал) | `{ type, name, description, avatar, bg, memberIds, creatorId }` |
| `POST` | `/api/chats/message` | Отправка сообщения в мессенджер (текст + вложения + ответ) | `{ chatId, senderId, senderName, senderAvatar, senderPhoto, text, attachments, replyTo }` |
| `POST` | `/api/chats/message/reaction` | Реакция на сообщение в чате (эмодзи) | `{ messageId, emoji, userId }` |
| `POST` | `/api/chats/message/delete` | Удаление сообщения из чата | `{ id }` |
| `POST` | `/api/chats/delete` | Удаление чата | `{ chatId }` |

## 5. Особенности интерфейса (`Classroom.html` / `index.html`)

1. **Telegram Web Реплика мессенджера («Чаты»)**:
   - Доступен из бокового меню (иконка самолётика и надпись «Чаты»).
   - Раздел на всю страницу с левой колонкой диалогов и правой областью чата.
   - **Фильтры по категориям (папки Telegram)**: «Все», «Личные», «Группы», «Каналы».
   - **Живой поиск**: фильтрация списка по названию чата или тексту последнего сообщения.
   - **Создание диалогов, групп и каналов**: модальное окно `#modal-create-chat` с выбором типа чата и участников из базы.
   - **Пузыри сообщений в стиле Telegram**:
     - Свои сообщения: справа, аутентичный телеграм-зеленый/темный фон (`#effedd` / `#2b5278`), время и двойная галочка (`check-double`).
     - Сообщения собеседников: слева, белый/темный фон (`#ffffff` / `#212d3b`), круглый аватар и имя отправителя.
   - **Цитаты и ответы (Quote Reply)**: кнопка ответа на сообщении, плашка ответа над полем ввода (`#chat-reply-preview`) и цитата внутри сообщения в стиле Telegram.
   - **Реакции на сообщения**: всплывающее меню реакций (👍, ❤️, 🔥, 😂, 👏) и отображение счетчиков реакций на пузырях сообщений.
   - **Удаление сообщений**: кнопка удаления для автора сообщения (`/api/chats/message/delete`).
   - **Встроенный Emoji Picker**: кнопка смайлика открывает сетку эмодзи для быстрой вставки.
   - **Вложения фото и видео**: отправка фото и видео, при клике открывается встроенный медиаплеер без перехода на новую вкладку!
   - **Быстрая отправка**: клавиша `Enter` (новая строка по `Shift+Enter`).

2. **Список задач («Список задач» / To-Do) — точная копия Google Classroom**:
   - Соответствует оригинальному Google Classroom (по скриншоту):
   - **Вкладки сверху**: «Назначено», «Пропущен срок сдачи», «Выполнено» с динамическими счетчиками.
   - **Выпадающий фильтр курсов**: «Все курсы» или конкретный предмет.
   - **Раскрывающиеся аккордеоны с шевронами**:
     - В «Назначено»: «Без срока сдачи», «На этой неделе», «Следующая неделя», «Не сейчас».
     - В «Пропущен срок сдачи»: «На прошлой неделе», «Ранее» (красные бейджи).
     - В «Выполнено»: «Без срока сдачи», «Сдано ранее» (зеленые статусы и оценки).
   - Строки заданий с круглой синей иконкой планшета (`fa-clipboard-list`), названием, курсом и сроком сдачи. Клик открывает задание на всю страницу.

3. **Создание задания на весь экран (`#view-create-assignment`)**:
   - Вместо маленького модального окна — полноэкранная рабочая область преподавателя.
   - Заголовок задания, требования и инструкции, максимальный балл, дедлайн, тема (раздел).
   - **Прикрепление материалов преподавателя**:
     - Загрузка файлов с ПК (с авто-сжатием изображений и чтением файлов);
     - Веб-ссылки;
     - Видео с YouTube;
     - Карточки предпросмотра прикрепленных материалов с возможностью удаления.
   - Публикация сохраняет материалы в задании (`attachments`) и отображает их на странице задания (`#view-assignment-detail`).

4. **Встроенный полноэкранный медиаплеер и просмотрщик фото (`#modal-media-viewer`)**:
   - При клике на любое прикрепленное фото или видео (в ленте курса, в задании преподавателя, в решениях учеников, в чате) файл **НЕ открывается в новой вкладке браузера**!
   - Открывается темный оверлей на весь экран с красивой анимацией.
   - **Видеоплеер**: воспроизведение видео с кнопкой прямого скачивания на устройство пользователя («Скачать видео»), а также просмотр видео YouTube.
   - Закрытие по кнопке с крестиком, клику на фон или нажатию клавиши `Escape`.

5. **Отказоустойчивость и локально-сетевой паритет (Local-First)**:
   - Все ключевые действия (регистрация аккаунта, создание курса, публикация записи, создание задания, отправка сообщения) выполняются **мгновенно (0 мс)** в локальном состоянии `appState` и `localStorage`.
   - Сетевые вызовы к серверу снабжены тайм-аутом `AbortController(1200ms)` — если сервер офлайн или клиент открыт через `file:///`, интерфейс ни на миллисекунду не зависает и не блокирует кнопки.
   - Все поля ввода форм снабжены иконками Font Awesome и поддержкой отправки по нажатию клавиши `Enter`.

## 6. Советы по расширению и доработке для ИИ

- **Синхронизация данных**: каждые 3 секунды клиент опрашивает `/api/data`. Если клиент находится в разделе «Чаты», сообщения и список диалогов обновляются на лету без мерцания интерфейса.
- **Масштабирование бэкенда**: `server.py` не имеет внешних зависимостей. Для запуска в Docker достаточно базового образа `python:3.11-alpine`.
